# Configuración general

La plataforma cuenta con opciones de administración que permiten ajustar parámetros generales del sistema.

## ¿Para qué sirve?

Permite mantener actualizadas configuraciones necesarias para el funcionamiento de los distintos módulos.

## Ejemplos

- parámetros generales;
- valores configurables;
- permisos;
- opciones operativas.
