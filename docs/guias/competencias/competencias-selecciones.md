# Competencias Selecciones

La sección **Competencias Selecciones** permite administrar las competencias de selecciones y avanzar desde su configuración inicial hasta el panel operativo de cada categoría.

## 1. Listado de competencias

Desde el menú principal ingresar a:

**Competencias → Competencias Selecciones**

![Listado de Competencias Selecciones](/img/guias/competencias/selecciones/1menucompetencias.png)

La pantalla presenta las competencias registradas y permite identificar cada una mediante información como:

- Logo.
- Disciplina.
- Nombre.
- Género.
- Temporada.
- Categorías.

### Acciones

Desde el listado se puede:

- seleccionar **Nuevo** para registrar una nueva competencia;
- seleccionar el ícono de **edición** para modificar una competencia existente;
- seleccionar **Categoría** para administrar las categorías asociadas.

---

## 2. Configuración de la competencia

Al seleccionar el ícono de edición se accede a la configuración de la competencia.

![Configuración de la competencia](/img/guias/competencias/selecciones/2edicioncargacompetencia.png)

### Datos del Torneo

En esta sección se configura la información general de la competencia:

- Nombre de la competencia.
- Nombre abreviado.
- Disciplina.
- Género.
- Temporada.
- Tiempo límite de entrega de planilla.
- Logo.
- Fecha de inicio.
- Fecha final.
- Plantilla Excel.
- Estado del torneo.

También se encuentra la opción:

**Activar aprobación post fecha**

Esta opción permite habilitar la **aprobación de documentos después de la fecha de cierre**.

### Configuraciones para partidos

Permite establecer parámetros utilizados durante los partidos, como:

- Límite de titulares por partido.
- Entrega de alineación.
- Límite de cuerpo técnico por partido.
- Cantidad de fechas.
- Tiempo por período.
- Tiempo de descanso.
- Tiempo extra.

### Lista de Buena Fe

Permite definir los límites de:

- Cantidad de atletas.
- Cantidad de oficiales.
- Extras.
- Sustituciones para atletas.
- Sustituciones para cuerpo técnico.

### Rooming List

Permite establecer límites relacionados con las habitaciones de la delegación:

- Habitaciones individuales.
- Habitaciones dobles.
- Habitaciones triples.
- Habitaciones cuádruples.
- Habitaciones quíntuples.

---

## 3. Categorías de la competencia

Desde **Categoría** se accede a las categorías asociadas a la competencia.

![Categorías de la competencia](/img/guias/competencias/selecciones/3asignarcategoria.png)

La pantalla permite:

- consultar las categorías asignadas;
- editar una categoría mediante el ícono de edición;
- seleccionar **Asignar Categoría** para incorporar una nueva;
- seleccionar **Ver Competencia** para acceder al panel operativo de una categoría;
- seleccionar **Volver** para regresar al listado de competencias.

---

## 4. Asignar una categoría

Al seleccionar **Asignar Categoría** se presenta el formulario de registro.

![Registro de categoría](/img/guias/competencias/selecciones/4registrocategoria.png)

El formulario permite definir:

- **Categoría** *
- **Nacidos desde**
- **Nacidos hasta**
- **Género**

Los campos marcados con `*` son obligatorios.

Para confirmar la operación se utiliza **Asignar Categoría**.

La opción **Cancelar** permite regresar sin completar la asignación.

---

## 5. Panel operativo de la competencia

Al seleccionar **Ver Competencia** se accede al panel correspondiente a la categoría seleccionada.

![Panel operativo de la competencia](/img/guias/competencias/selecciones/5landingcompetencia.png)

Este panel concentra las principales herramientas disponibles para la operación de la competencia.

### Acceso rápido

Entre las opciones disponibles se encuentran:

- **Equipos**
- **Agenda de Actividades Equipos**
- **Sub Competencias**
- **Indumentarias Generales**
- **Regulaciones**
- **Actividades**
- **Info General Equipos**
- **Reconocimiento Evolución**
- **Envío de Alineación**
- **Reglamento**
- **Hotel**

### Reportes

El panel también presenta accesos a:

- **Reconocimiento Evolución General**
- **Reconocimiento Evolución Sub Competencias**
- **Boletín Técnico**
- **Boletín Técnico Diario**
- **Lista de Buena Fe**

Estas opciones constituyen el punto de entrada para continuar documentando los procesos específicos de cada competencia.

---

## Flujo completo

El recorrido de una competencia de selecciones queda organizado de la siguiente manera:

**Competencias Selecciones**

→ configuración de la competencia

→ administración de categorías

→ asignación de categorías

→ acceso al panel operativo

Desde el panel operativo se continúa con las distintas funcionalidades de la competencia.
