# Operación multi-organización

JUEGA permite que múltiples organizaciones, suborganizaciones y equipos operen dentro de una misma plataforma.

## Qué permite lograr

- Operar simultáneamente con múltiples organizaciones.
- Administrar suborganizaciones y equipos.
- Permitir que distintas Asociaciones Miembro administren sus propias competiciones y procesos.
- Adaptar la operación según la organización.
- Proporcionar vistas personalizadas e identidad visual propia por Asociación Miembro.

## Procesos incluidos

Esta capacidad atraviesa los procesos de competición, equipos, participantes, partidos y administración.

## Reglas y controles

La operación puede configurarse de manera diferenciada según organización, asociación o competición.

## Trazabilidad

La información se administra dentro de una plataforma común manteniendo el contexto organizacional correspondiente.

## Usuarios involucrados

- CONMEBOL.
- Asociaciones Miembro.
- Organizaciones.
- Equipos.
- Administradores.

## Capacidades relacionadas

- Gestión de competiciones.
- Gestión de equipos y delegaciones.
- Seguridad, acceso e internacionalización.

## Evolución reciente

Las mejoras relevantes serán incorporadas progresivamente.
