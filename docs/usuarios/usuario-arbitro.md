# Usuario de Árbitro

La plataforma tiene un tipo de usuario para los árbitros.

## ¿Para qué sirve?

Permite cargar los datos de todo lo ocurrido en un partido, desde goles hasta sustituciones.

## Funcionalidades principales

- Carga de fases de partido (Primer tiempo, Segundo tiempo) y su duración 
- Carga de goles y penales
- Carga de tarjetas amarillas
- Carga de tarjetas rojas
- Carga de sustituciones 
- Crear informe de partido
