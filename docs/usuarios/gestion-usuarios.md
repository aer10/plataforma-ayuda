# Gestión de usuarios

La plataforma permite administrar los usuarios que tienen acceso al sistema.

## ¿Para qué sirve?

Permite controlar quién puede ingresar a la plataforma y qué acciones puede realizar.

## Funcionalidades principales

- Alta de usuarios
- Edición de datos
- Activación o desactivación
- Asignación de perfiles o permisos
