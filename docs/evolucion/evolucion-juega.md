# Evolución y novedades de JUEGA

Esta sección registra cambios que amplían o modifican de manera relevante el alcance funcional de JUEGA.

## Qué se documentará

- Nuevas capacidades incorporadas.
- Ampliaciones de capacidades existentes.
- Nuevos procesos soportados.
- Cambios relevantes en reglas, controles o trazabilidad.
- Nuevas integraciones.
- Mejoras con impacto funcional para organizaciones y usuarios.

## Novedades

Las novedades serán incorporadas a medida que se disponga de información verificada sobre las mejoras y su fecha de incorporación.
