# Guía funcional de JUEGA

Esta documentación resume las principales funcionalidades disponibles en la plataforma JUEGA.

El objetivo es contar con una referencia simple y actualizada sobre:

- qué funcionalidades están disponibles;
- para qué sirve cada módulo;
- cómo se utiliza cada función;
- qué mejoras se van incorporando.

## ¿Cómo utilizar esta guía?

Podés navegar por las distintas categorías desde el menú lateral.

Cada funcionalidad contiene una explicación resumida, los pasos principales para utilizarla y consideraciones relevantes.
