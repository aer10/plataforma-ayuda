# Exportación de información a Excel

La plataforma permite exportar determinados listados y reportes a formato Excel.

## ¿Para qué sirve?

Permite trabajar con la información fuera de la plataforma para tareas de control, análisis o intercambio de datos.

## ¿Cómo funciona?

1. Ingresar al reporte correspondiente.
2. Aplicar los filtros necesarios.
3. Seleccionar la opción de exportación.
4. Descargar el archivo generado.
