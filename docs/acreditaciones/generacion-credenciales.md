# Generación de credenciales

La plataforma permite generar automáticamente credenciales a partir de la información registrada de cada participante.

## ¿Para qué sirve?

Permite obtener una credencial lista para impresión utilizando los datos existentes en la plataforma.

## Información incluida

La credencial puede incluir:

- nombre y apellido;
- documento;
- fotografía;
- equipo;
- organización;
- país;
- posición o función.

## ¿Cómo funciona?

1. Ingresar al módulo correspondiente.
2. Buscar o seleccionar al participante.
3. Seleccionar la opción **Generar credencial**.
4. El sistema genera automáticamente el documento.
5. Descargar o imprimir la credencial.

## Consideraciones

La información que aparece en la credencial depende de los datos registrados previamente en la plataforma.
